# 📱 Nice Gadgets Store

A responsive web application for browsing and viewing details of mobile phones, tablets and accessories. Users can filter, sort, and add gadgets to the cart or favorites list. It offers a smooth and user-friendly shopping-like experience.

# ✨ Features

- Responsive design for desktop, tablet and mobile
- Product list with sorting and filtering
- Favorites and cart functionality using local storage
- Dynamic routing with React Router
- Custom products slider
- Loading spinners for better UX
- Scroll to top button

# 🛠️ Technologies Used

- React – UI built with functional components and hooks.
- TypeScript – Ensures type safety across the app.
- React Router – Handles page navigation and routing.
- Context API – Manages global states like cart and favorites.
- SCSS Modules – Styles are scoped and modular.
- React Spinners – Displays loading indicators during data fetch.
- Vite – Used for fast development and optimized builds.
- Static JSON (public folder) – Simulated API data loaded from `public` folder

# 🚀 Getting Started

Include these instructions on how to set up the project locally:

1. **Clone the repository**

   ```bash
   git clone https://github.com/yuliia-fil/Nice-Gadgets-store.git
   cd Nice-Gadgets-store

   ```

2. **Install dependencies:**

   Using `npm`

   ```bash
   npm install

   ```

   Using `yarn`

   ```bash
   yarn install
   ```

3. **Run the project locally:**

   Using `npm`

   ```bash
   npm start

   ```

   Using `yarn`

   ```bash
   yarn start
   ```
